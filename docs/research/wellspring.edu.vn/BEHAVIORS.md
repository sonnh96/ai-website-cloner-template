# Behavior Bible — wellspring.edu.vn (Homepage)

## Global

- **Header scroll state:** `header` toggles CSS class `sticky-null` → `sticky-down` the moment `scrollY` leaves 0. Header is `position: fixed`, height 119px, white background, no shadow, at all scroll positions observed. No visible restyle currently tied to the class change — implement the hook (data attribute or class swap) but don't invent extra visual chrome.
- **Cookie consent banner:** bottom-fixed bar, "Chấp nhận Cookie" heading, decline/accept buttons ("Từ chối" / "Chấp nhận"), link to cookie policy. Dismiss-once, likely stored in localStorage/cookie.
- **AOS (Animate On Scroll):** certificate/partner-logos strip has `aos-init` class → fades/slides in when scrolled into view. Standard AOS default easing/duration is a reasonable default (no custom values captured).
- **GSAP + ScrollTrigger:** confirmed via `.pin-spacer` wrapper element auto-generated by ScrollTrigger around the hero section.

## Hero — scroll-driven pin animation (INTERACTION MODEL: scroll-driven, not click)

The hero section is pinned (`position: fixed`-like behavior via GSAP) for ~2567px of scroll distance while its internal content morphs through stages purely as a function of scroll progress:

1. **Stage A (scrollY ≈ 0):** White background. Large bold wordmark "WELLSPRING" in dark charcoal/black, "TRƯỜNG HỌC HẠNH PHÚC" in orange handwritten font underneath, "Chào mừng quý Phụ huynh đến với" navy intro line above. "Cuộn để khám phá" (scroll to explore) prompt with a hand-drawn squiggle arrow icon below.
2. **Stage B (small scroll):** The letters of "WELLSPRING" become a **mask revealing a background video** (kids in a science lab). Each letter glyph acts as a viewport into the video — visible as the video content showing through the letter shapes while the rest of the viewport stays white.
3. **Stage C (mid scroll):** The masked video reveal expands / the video takes over more of the frame — an S-shaped curve (large morphing blob/curve shape, dark charcoal fill) sweeps across the viewport as a transition wipe.
4. **Stage D (further scroll):** Video plays full-bleed full-viewport (kids painting, overhead shot) with a small circular play/expand icon button bottom-center ("Xem trọn vẹn bộ phim" / view full film — click opens full video, not yet tested for modal vs new tab).
5. **Stage E (end of pin):** Content settles into Section 1's static layout (video shrinks to an inline `<video>`/image block, text content unpins and resumes normal document flow).

**Implementation approach:** GSAP `ScrollTrigger` with `pin: true`, `scrub: true` (smooth scrubbing tied 1:1 to scroll, not click-triggered), animating clip-path/mask on the text, a blob/curve SVG or clip-path wipe, and video opacity/scale. Exact easing/keyframe percentages were not individually measured (would require frame-by-frame scroll capture); builder should approximate the 5-stage sequence above with `ScrollTrigger.create({ trigger, pin: true, scrub: true, start: 'top top', end: '+=2567' })` and tween the mask/video/text opacity across that range.

## Responsive sweep

Could not visually confirm mobile/tablet renders (sandboxed browser window would not go below 1440px viewport — see PAGE_TOPOLOGY.md limitation note). Confirmed breakpoints from live stylesheets: `480px`, `768px`, `1440px`, `1930px`. Apply mobile-first Tailwind breakpoints at roughly `sm:480px`, `md:768px`, `xl:1440px`, `2xl:1930px` and verify visually against the built dev server at 390/768/1440 during Phase 5 QA.

Expected (standard, not yet visually confirmed) responsive behavior:
- Header: top utility bar likely collapses/hides on mobile; main nav collapses to a hamburger + slide-in drawer.
- Hero: pin-scroll animation likely simplifies or shortens on mobile (GSAP ScrollTrigger commonly disables/reduces pin distance below a breakpoint — implement a `matchMedia` guard disabling `pin` under 768px, falling back to a simpler fade-in).
- Multi-column sections (stats, WISers acronym, news grid, campus cards): stack to single column below 768px.
- Footer link columns: stack vertically on mobile.
